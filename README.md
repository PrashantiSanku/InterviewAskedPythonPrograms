    * First and foremost step is to open a browser and type Python Download or paste link (https://www.python.org/downloads/)
  Step 2: Choose the Python Version
    * Once you landed on the download page choose the Python Version
    * Click on the version you want to download. – Python 3.13.2 (the latest stable release as of now is Python 3.13.21.

    * Once the download is complete, run the installer program. On Windows , it will typically be a .exe file , on macOS , it will be a .pkg file , and on Linux , it will be a .tar.gz file .

## List Comprehension in Python
  List comprehension offers a shorter syntax when you want to create a new list based on the values of an existing list. List comprehension is a way to create lists using a concise syntax. It allows us to generate a new list by applying an expression 
  to each item in an existing iterable (such as a list or range). This helps us to write cleaner, more readable code compared to traditional looping techniques.

## Functions
    In Python function is a group of related statements that perform a specific task.

## Lambda Function
    A Lambda Function is a small anonymous function. A lambda function can take any number of arguments, but can only have one expression.

## List
    Lists are used to store multiple items in a single variable. List items are ordered, changeable, and allow duplicate values. List items are indexed, the first item has index [0], the second item has index [1] etc. List is very similar to arrays.
    Lists are created by []. Lists are mutable.

## Tuple
    Tuples are used to store multiple items in a single variable. Tuples are created by (). Tuples are immutable. Tuples are very similar to list but once a tuple is created, you cannot add, delete, replace, reorder elements.

## Dictionary
  Dictionary is a Python data type that is used to store key value pairs. It enables you to quickly retrieve, add, remove, modify, values using key. Dictionary is very similar to Hahmap in Java. Dictionary are mutable. Dictionary are created by {}

## For loop
    A for loop is used for iterating over a sequence (that is either a list, a tuple, a dictionary, a set, or a string).
